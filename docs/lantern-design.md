# 소원 등불 (Wish Lanterns) — Deep Dive

> 거창하지 않게, 누구나 들어와서 등불 하나 띄우고 잠깐 쉬다 가는 곳.

## 1. 한 줄 컨셉
밤 호숫가에 앉아 등불에 한마디를 적어 띄운다. 다른 사람들의 등불이 함께 떠다니고, 그걸 바라보거나 살짝 "따뜻함"을 보내줄 수 있다. 이기고 지는 것 없이, 머무는 것 자체가 플레이.

## 2. 플레이 흐름 (1~3분이면 한 바퀴)
1. **도착** — 잔잔한 물소리, 반딧불, 멀리 떠 있는 등불들. 타이틀 위로 "클릭해서 시작".
2. **등불 고르기** — 색 3~5가지(주황·분홍·하늘·연두·보라). 모양은 하나로 단순하게.
3. **한마디 적기** — 최대 30자. 쓰기 어려운 사람을 위해 문구 고르기 제공
   ("오늘도 수고했어", "다 잘 될 거야", "보고 싶어", "고마워" …) + 그냥 비워둬도 됨.
4. **띄우기** — 손을 떼면 등불이 물 위에 내려앉아 천천히 멀어지고, 일부는 하늘로 올라감.
5. **머물기** — 떠다니는 다른 등불을 누르면 그 한마디가 잠깐 보임. ♡를 누르면 등불이 한 번 반짝(작은 응원).
6. **떠나기 / 다시 오기** — 내가 띄운 등불 수, 받은 반짝임 수가 조용히 기록됨.

## 3. "다양한 사람이 참여하는 느낌"을 만드는 방법
| 방식 | 느낌 | 난이도 |
|---|---|---|
| A. 실시간 공유 (지금 접속한 사람들의 등불이 같이 떠다님) | 진짜 "같이 있다" | 중 — Genex 멀티플레이 SDK, 게시 후 테스트 |
| B. 쌓이는 호수 (지난 사람들의 등불이 남아 있음) | 들어올 때마다 풍성 | 중~상 — 공유 저장소 필요 |
| C. 혼자 모드 + 가상 등불 (미리 준비된 따뜻한 문구가 떠다님) | 처음부터 비어 보이지 않음 | 하 |

**추천:** C로 시작해서 언제나 호수가 비어 보이지 않게 하고, 그 위에 A(실시간)를 얹는다. 접속자가 없으면 가상 등불, 있으면 실제 사람 등불이 섞임.

## 4. 안전 장치 (자유 문구는 꼭 필요)
- 짧은 길이 제한 + 기본 금칙어 필터
- 남의 등불 숨기기 버튼(내 화면에서만)
- 원하면 "문구 고르기만" 모드로 완전히 안전하게 운영 가능

## 5. 분위기 / 비주얼
- 3D 저폴리, 따뜻한 밤: 짙은 남색 하늘, 은하수, 잔잔히 반사되는 물, 주황빛 등불의 부드러운 빛 번짐(블룸)
- 참고: Sky: Children of the Light의 촛불 감성, 라푼젤 등불 장면
- 소리: 물결, 풀벌레, 등불 놓을 때 부드러운 "퐁", 잔잔한 피아노/앰비언트

## 6. 작은 재미 요소 (선택)
- 밤이 천천히 새벽으로 바뀌는 시간 흐름
- 가끔 유성 — 그 순간 띄운 등불은 하늘 높이 올라감
- 내 등불 도감: 지금까지 띄운 색·문구 모아보기

## 7. 하지 않는 것
점수, 경쟁, 랭킹, 레벨, 과금 압박, 복잡한 조작.

## 8. 1차 빌드 범위 제안
- 호숫가 3D 장면 + 등불 고르기·적기·띄우기
- 가상 등불이 떠다니고 눌러서 읽기, ♡ 반짝임
- 내 기록 로컬 저장
- (2차) 실시간 다른 사람 등불 공유
